# Interfaces em C#

Exercicio de interface: `IFormaGeometrica` define `CalcularArea` e
`CalcularPerimetro`, e tres classes (`Circulo`, `Retangulo`, `Triangulo`)
implementam cada uma do seu jeito.

## O que pratiquei

- Declarar e implementar uma interface
- Polimorfismo: uma `List<IFormaGeometrica>` guardando objetos de tipos
  diferentes e chamando o mesmo metodo em cada um
- Construtor com parametros pra inicializar os campos

## Como rodar

```
dotnet run
```
